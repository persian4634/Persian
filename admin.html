لوگوی سایت

اگه یه لوگو بذارید، به‌جای نوشته «پرشین» تو هدر بالای صفحه نشون داده می‌شه. عکس با پس‌زمینه شفاف (PNG) و حدود ۲۰۰×۶۰ پیکسل بهترین نتیجه رو می‌ده.

دریافت نظرات مشتری‌ها (خصوصی)

فرم نظرات سایت با یه سرویس رایگان (Web3Forms) کار می‌کنه که نظرات رو مستقیم به ایمیل شما می‌فرسته، بدون اینکه عمومی نمایش داده بشن.
مراحل: به web3forms.com برید، ایمیلتون رو وارد کنید، یه «Access Key» رایگان می‌گیرید (نیازی به ثبت‌نام کامل نیست) — همون کلید رو اینجا بچسبونید.

ورود با گوگل (اختیاری)

اگه می‌خوای مشتری‌ها با یه کلیک با حساب گوگل وارد بشن، یه «Client ID» رایگان از Google Cloud Console بگیر (APIs & Services ← Credentials ← OAuth client ID ← Web application) و آدرس سایتت رو توی «Authorized JavaScript origins» بنویس. بعد Client ID رو اینجا بچسبون.
تا وقتی خالی باشه، فقط ورود با اسم و شماره نشون داده می‌شه.

شماره واتساپ فروشگاه

سفارش‌هایی که از سبد خرید تکمیل می‌شن، به این شماره تو واتساپ ارسال می‌شن. شماره رو با کد کشور و بدون صفر اول بنویسید (مثلاً برای 0912xxxxxxx بنویسید 98912xxxxxxx).

کدهای تخفیف

هر خط یه کد: اول کد، بعد = و بعد درصد تخفیف. مثلاً:
SALE10=10
NOROOZ=20
مشتری تو سبد خرید کد رو وارد می‌کنه و تخفیف رو می‌بینه. دقت کنید چون سایت استاتیکه، کدها تو فایل تنظیمات سایت ذخیره می‌شن و کسی که اون فایل رو باز کنه می‌تونه ببینه‌شون؛ پس کد خیلی محرمانه نذارید.

شبکه‌های اجتماعی

هر کدوم رو که پر کنید، پایین صفحه سایت به‌عنوان آیکون قابل‌کلیک نشون داده می‌شه. آدرس کامل (با https://) وارد کنید. اگه خالی بذارید، اون آیکون اصلاً نشون داده نمی‌شه.

درباره ما / قوانین و مقررات

این متن‌ها و عکس با زدن لینک «درباره ما» (پایین صفحه سایت) نشون داده می‌شن.

این عکس، جدا از لوگوی هدر سایته — مخصوص دایره‌ی بالای صفحه «درباره ما»ست. عکس مربعی (مثلاً ۴۰۰×۴۰۰) بهترین نتیجه رو می‌ده. اگه عکس جدید انتخاب نکنید، عکس قبلی حفظ می‌شه.

عکس صفحه منو

این عکس بالای منوی همبرگری (به‌جای رنگ ساده) نشون داده می‌شه. عکس افقی و حدود ۹۰۰×۴۵۰ پیکسل بهترین نتیجه رو می‌ده.

استوری‌ها (ردیف دایره‌ای زیر هدر)

برای هر استوری یه عکس و یه عنوان کوتاه بذارید. عکس مربعی (مثلاً ۶۰۰×۶۰۰) بهترین نتیجه رو می‌ده. اگه عکس جدید انتخاب نکنید، عکس قبلی همون استوری حفظ می‌شه. برای هر استوری می‌تونید تعیین کنید چند روز روی سایت بمونه (۲ روز، ۳ روز، ۱ هفته، ۱ ماه یا بدون انقضا)؛ بعد از اون تاریخ، خودکار از سایت حذف می‌شه.

کارت‌های بزرگ هدر (بالای صفحه)

برای هر کارت یه عکس و یه متن کوتاه (که روی عکس نشون داده می‌شه) بذارید. عکس عمودی حدود ۶۰۰×۸۰۰ پیکسل بهترین نتیجه رو می‌ده. این بخش کاملاً مستقل از استوری‌هاست. اگه عکس جدید انتخاب نکنید، عکس قبلی همون کارت حفظ می‌شه.
